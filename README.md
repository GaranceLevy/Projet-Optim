Ce travail constitue notre rendu final pour l'UE d'Optimisation du M2 Maths en Action.

Nous cherchons à modéliser le risque de blessure d'athlètes de haut niveau à partir de leur données d'entrainement avec un modèle de regression logistique.

Le travail se divise dans les sections suivantes :
1. Contexte et Modélisation
2. Etude des fonctions $h$ et $f$
3. Premier algorithme : FISTA
4. Deuxième algorithme : Chambolle-Pock
5. Troisième algorithme : ADAM
6. Comparaison des trois algorithmes
7. Conclusion
